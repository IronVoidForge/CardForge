Setup directions

Mobile/PC mode: run cardforge ui serve --mode both --host 0.0.0.0 --password "your-password", then open / on PC or /m on phone/tablet.

LM Studio: start LM Studio server on your model machine and use its OpenAI-compatible URL, usually http://<machine-ip>:1234/v1.

ComfyUI: start ComfyUI with network access and use http://<machine-ip>:8188. Keep input/output paths matching that ComfyUI machine.

cardforge llm configure --base-url http://192.168.1.42:1234/v1 --model your-model
cardforge comfy configure --base-url http://192.168.1.42:8188 --input-dir C:\ComfyUIInstall\input --output-dir C:\ComfyUIInstall\output
cardforge llm health --json
cardforge comfy health --json
